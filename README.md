🚀 Project Team Finder
Project Team Finder is a simple web-based application that helps students find suitable teammates for their college projects based on their skills and interests.

📌 Features
🔍 Search students by name or skill
🧑‍💻 Filter students based on skills
➕ Add students to your project team
❌ Remove team members
👥 View the selected team members
📊 Display team member count
🚀 Create a project team
🛠️ Technologies Used
HTML
CSS
JavaScript
🎯 Purpose
The main purpose of this project is to make it easier for students to find suitable teammates for college projects according to their technical skills and interests.
